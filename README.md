## Personal Expense Tracker

A Python-based Personal Expense Tracker that helps users record, manage, analyze, and visualize their daily expenses.

##  Project Overview

The Personal Expense Tracker is a beginner-friendly Python project developed using **Python, Pandas, Matplotlib, JSON, and Jupyter Notebook**.

The application allows users to manage their expenses and understand their spending patterns through data analysis and visualizations.

##  Features

-  Add new expenses
-  View all expenses
-  Edit existing expenses
-  Delete expenses
-  Save expenses using JSON
-  Load previously saved expenses
-  Categorize expenses
-  Category-wise expense analysis
-  Search expenses by category
-  Monthly spending analysis
-  Expense visualization
-  Pandas-based expense dashboard

##  Technologies Used

-  Python
-  Pandas
-  Matplotlib
-  JSON
-  Jupyter Notebook
